# Thesis documents

Privacy-impact (DPIA), risk-assessment (RA) and data-inventory (PDIM) documents written for the capstone thesis panel. They are **historical records, not specifications**: do not derive requirements or code behavior from them. Their contents are kept as submitted.

These files are matched by the root `.gitignore` (`DPIA_*`, `PDIM_*`, `RA_*`), so they live only in the author's working copy and are not published with the repository.
